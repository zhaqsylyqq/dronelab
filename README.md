# DroneLab 🚁

3D-конструктор дрона — мобильное приложение для Android и iPhone.
Выбираешь раму, моторы, батарею, камеру — и сразу видишь дрон в 3D, цену и массу.

Сделано на обычных HTML/CSS/JS + [three.js](https://threejs.org) (3D) + [Capacitor](https://capacitorjs.com) (превращает сайт в приложение).

> Подробно о том, как всё устроено внутри — в файле [КАК_ЭТО_РАБОТАЕТ.md](КАК_ЭТО_РАБОТАЕТ.md).

## Как запустить у себя

### Шаг 0. Что нужно установить (один раз)

| Что | Зачем | Где взять |
|---|---|---|
| **Git** | скачать проект | git-scm.com |
| **Node.js 22 или новее** | инструменты для сборки | nodejs.org (бери версию LTS) |
| **Android Studio** | запуск на Android | developer.android.com/studio |
| **Xcode** (только Mac) | запуск на iPhone | App Store |

Проверить, что всё стоит — открой терминал и введи:
```
git --version
node -v
```
Обе команды должны показать номер версии (у node — `v22...` или больше).

> 💡 Приложение для **iPhone** можно собрать **только на Mac**. На Windows — только Android.

### Шаг 1. Скачай проект

Открой терминал в папке, куда хочешь положить проект (например, Рабочий стол), и выполни:
```
git clone <ССЫЛКА_НА_РЕПОЗИТОРИЙ>
cd <ИМЯ_ПАПКИ>
```
Ссылку возьми на странице репозитория на GitHub: зелёная кнопка **Code → HTTPS → скопировать**.

> ⚠️ Не клади проект в папку, где в пути есть русские буквы или пробелы
> (например `C:\Users\Иван\Мои проекты\`) — Android Studio на этом иногда спотыкается.
> Лучше что-то вроде `C:\projects\dronelab`.

### Шаг 2. Скачай инструменты
```
npm install
```
Появится папка `node_modules` — это нормально. Если в конце напишет про
"vulnerabilities" — не страшно, **не** запускай `npm audit fix --force`.

### Шаг 3. Подготовь Android и iOS
```
npm run sync
```
Эта команда копирует сайт из папки `www/` внутрь Android- и iOS-проектов.

### Шаг 4а. Запуск на Android
```
npm run android
```
Откроется Android Studio. Дальше:
1. Первый раз дождись, пока внизу закончится **Gradle sync** (5–15 минут, скачивает детали).
2. Справа **Device Manager** (иконка телефончика) → **+** → **Create Virtual Device** →
   выбери, например, **Pixel 8** → выбери систему (верхнюю, нажми скачать) → **Finish**.
3. Наверху выбери этот телефон и нажми зелёный **▶ Run**.

На настоящем телефоне: включи "Режим разработчика" и "Отладку по USB",
подключи кабелем — он появится в том же списке.

### Шаг 4б. Запуск на iPhone (только Mac)
```
npm run ios
```
Откроется Xcode. Дальше:
1. Слева синяя иконка **App** → вкладка **Signing & Capabilities** → **Team** →
   выбери свой Apple ID (бесплатного хватит).
2. Наверху выбери симулятор (например, iPhone 16) или свой iPhone по кабелю → **▶**.
3. На своём iPhone первый раз: включи *Настройки → Конфиденциальность и безопасность →
   Режим разработчика*, а потом *Настройки → Основные → VPN и управление устройством → Доверять*.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `'npm' не является командой` | Не установлен Node.js, или терминал открыт до установки — закрой и открой заново |
| `'cap' не является командой` | Забыл `npm install` |
| Android Studio: ошибки Gradle / SDK | *Tools → SDK Manager* → поставь последнюю версию Android → *Apply*, потом *File → Sync Project with Gradle Files* |
| Белый экран в приложении | Забыл `npm run sync`. Ошибки на Android видно в Chrome по адресу `chrome://inspect` |
| Xcode: "requires a development team" | Не выбран Team (шаг 4б, пункт 1) |

Больше ошибок и решений — в разделе 6 файла [КАК_ЭТО_РАБОТАЕТ.md](КАК_ЭТО_РАБОТАЕТ.md).

## Как вносить изменения

Меняй файлы **только в папке `www/`**, потом:
```
npm run sync
```
и снова жми ▶ в Android Studio / Xcode.

Если хочешь отправить свои изменения обратно в репозиторий:
```
git add .
git commit -m "Что я поменял"
git push
```
(для `push` тебя должны добавить в репозиторий как участника — *Settings → Collaborators* на GitHub).

## Без установки: просто посмотреть

Открыть сайт в браузере тоже можно, но не двойным кликом по файлу (браузер
запретит загрузку 3D-модулей), а через маленький сервер:
```
npx serve www
```
и открыть ссылку, которую покажет команда (обычно http://localhost:3000).
