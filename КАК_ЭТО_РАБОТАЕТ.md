# Как это работает — DroneLab

Привет! Это объяснение для новичка: что лежит в проекте, как оно устроено
и как запустить приложение на телефоне. Без сложных слов, обещаю.

---

## 1. Из чего состоит проект

Представь, что проект — это квартира. В ней есть жилая комната (то, что видит
человек), кладовка с инструментами и две "пристройки" — для Android и для iPhone.

```
drone_arnur/
│
├── www/                     ← ЖИЛАЯ КОМНАТА. Это и есть наше приложение.
│   ├── index.html           ← скелет страницы: заголовки, кнопки, списки
│   ├── css/style.css        ← внешний вид: цвета, размеры, отступы
│   ├── js/app.js            ← "мозг": 3D-дрон, подсчёт цены, кнопки
│   ├── libs/
│   │   ├── three/three.module.js   ← библиотека three.js (умеет рисовать 3D)
│   │   ├── three/OrbitControls.js  ← модуль "крути дрон пальцем"
│   │   └── capacitor.js            ← мостик к функциям телефона
│   └── fonts/               ← шрифт Inter (латиница + кириллица)
│
├── android/                 ← ПРИСТРОЙКА для Android (открывается в Android Studio)
├── ios/                     ← ПРИСТРОЙКА для iPhone (открывается в Xcode на Mac)
│
├── capacitor.config.json    ← паспорт приложения: имя, ID, где лежит сайт
├── package.json             ← список инструментов и короткие команды
├── node_modules/            ← КЛАДОВКА: скачанные инструменты (руками не трогаем)
│
├── index.html               ← твой исходный файл (не тронут)
├── index.original.html      ← запасная копия оригинала
└── КАК_ЭТО_РАБОТАЕТ.md      ← этот файл
```

**Главное правило:** всё, что ты меняешь в приложении, меняй **только в папке `www/`**.
Папки `android/` и `ios/` получают копию `www/` автоматически (об этом ниже).

### Что изменилось по сравнению с исходным сайтом

| Было | Стало | Зачем |
|---|---|---|
| Всё в одном `index.html` | Три файла: html, css, js | Проще найти нужное |
| three.js грузился из интернета | Лежит в `www/libs/three/` | Работает без интернета |
| Шрифт из Google Fonts | Лежит в `www/fonts/` | Работает без интернета |
| Кнопка "Скачать конфигурацию" | В приложении — "Поделиться" | В приложении скачивание не работает |
| Шапка залезала под чёлку | Отступы под чёлку и полоску жестов | Ничего не прячется |
| Главный дрон мешал листать страницу | Он крутится сам, пальцем не трогается | Страница листается нормально |
| На телефонах главный дрон уезжал за край | Исправлено (размер холста в CSS) | Дрон по центру |
| Кнопка "Остановить вращение" врала | Дрон в конструкторе сразу крутится | Кнопка работает с первого раза |
| Эффекты "при наведении мышкой" | Только на компьютере с мышкой | На телефоне кнопки не залипают |

## 2. Как работает 3D-сцена

Вся 3D-часть — это **съёмочная площадка в кино**. Посмотрим, кто на ней есть.
Код — в функции `createDrone` в файле `www/js/app.js`.

### Сцена (`THREE.Scene`) — это сама площадка
Пустая комната, куда мы ставим всё остальное: дрон, лампы, сетку на полу.
```js
const scene = new THREE.Scene();
```

### Камера (`THREE.PerspectiveCamera`) — это оператор с камерой
Она решает, *откуда* мы смотрим на дрон. Число `38` — насколько широко
камера "видит" (как зум на телефоне). `camera.position.set(5.6, 4.6, 6.5)` —
оператор стоит чуть сбоку и сверху.

### Свет — это осветители на площадке
Без света всё было бы чёрным, как комната ночью. У нас четыре лампы:
- `HemisphereLight` — **небо**: мягкий свет сверху голубоватый, снизу фиолетовый;
- `DirectionalLight` — **солнце**: яркий свет с одной стороны, даёт блики;
- два `PointLight` — **цветные лампочки** (голубая и фиолетовая), как подсветка в игровой комнате.

### Дрон — конструктор LEGO из кубиков и цилиндров
Никакой готовой 3D-модели нет! Дрон собран из простых фигур:
- `box(...)` — **кубик** (точнее, брусок). Из них сделаны корпус, лучи рамы и лопасти;
- `cylinder(...)` — **цилиндр** (как батарейка). Из них сделаны моторы, камера, антенна.

Каждая фигура = **форма** (Geometry: "какой формы") + **материал** (Material: "из чего",
то есть цвет, блеск, металл это или пластик). Вместе они называются `Mesh`.

Все детали складываются в одну "коробку" — `THREE.Group`. Если повернуть
или увеличить коробку, повернётся и увеличится весь дрон целиком.

Четыре луча с моторами делаются в цикле `for`: одна и та же инструкция
повторяется 4 раза для четырёх углов `[-1, 1], [1, 1], [-1, -1], [1, -1]`.

### Рендерер (`WebGLRenderer`) — это фотограф
Он берёт сцену и камеру и "фотографирует" их на `<canvas>` (холст на странице).

### Анимация — это мультик
Функция `animate()` вызывает сама себя примерно **60 раз в секунду**
(через `requestAnimationFrame`). Каждый раз она чуть-чуть поворачивает
пропеллеры и делает новый "кадр". Быстро сменяющиеся кадры = движение,
как в мультфильме из рисунков на краях тетради.

### OrbitControls — "крути пальцем"
Готовый модуль: ведёшь пальцем — камера летает вокруг дрона;
щипок двумя пальцами — приближение.

## 3. Как работают выпадающие списки, цена и масса

### Каталог — это "прайс-лист"
В начале `app.js` есть объект `catalog`. Это как таблица в магазине:
у каждой детали есть имя, цена (`price`) и вес в граммах (`weight`).
```js
frame: [
  { name: "Carbon Pro 5″", price: 90, weight: 120, size: 1.0 },
  ...
]
```

### Выпадающий список знает только номер
В `index.html` у каждого пункта списка есть `value="0"`, `value="1"`, `value="2"`.
Это **номер строчки** в прайс-листе (считаем с нуля, как программисты).

### Что происходит, когда выбираешь деталь
1. Список "кричит": *"меня поменяли!"* — это событие `change`.
2. Код записывает новый номер в `config` (это "корзина покупок").
3. Вызывается `updateSummary()` — **калькулятор**:
   - **Цена** = сумма цен всех 6 выбранных деталей;
   - **Масса** = 180 г (провода, винтики — условно) + вес всех деталей;
   - **Время полёта** — упрощённая формула: чем тяжелее дрон, тем меньше летает.
     `батарея.flight × 850 ÷ масса` → и показываем диапазон "от −2 до +3 минут";
   - **Класс**: большая рама → `LR` (дальний), маленькая → `MINI`, обычная → `PRO`.
4. Вызывается `updateModel()` — дрон в 3D увеличивается или уменьшается
   под размер выбранной рамы (`size`).

Важно: цифры **демонстрационные**, это не настоящая физика.

### Кнопка "Поделиться"
1. `makeConfigText()` собирает текст: что выбрано, цена, масса.
2. В приложении: `Filesystem` сохраняет текст во временный файл `dronelab-config.txt`,
   а `Share` открывает системное окно "Поделиться" (Telegram, почта, Файлы…).
3. В обычном браузере на компьютере: файл просто скачивается, как раньше.

## 4. Как сайт становится приложением

### Что такое WebView
**WebView** — это браузер без адресной строки и кнопок, "встроенный" внутрь приложения.

Аналогия: представь **телевизор**. Сам по себе он показывает что угодно.
WebView — это телевизор, который мы встроили в коробку с надписью "DroneLab"
и навсегда включили на наш канал. Человек видит только картинку — и думает,
что это обычное приложение.

- На Android внутри работает движок Chrome;
- На iPhone — движок Safari.

### Что такое Capacitor
**Capacitor** — это **набор "коробок" для телевизора** + **пульт**.

- **Коробки** — готовые пустые проекты для Android (`android/`) и iPhone (`ios/`),
  внутри которых уже стоит WebView и настроено всё скучное.
- **Пульт** — плагины. Сайт сам по себе не умеет открыть системное меню
  "Поделиться" или записать файл в память телефона. А через плагин — умеет:
  JavaScript говорит "нажми кнопку на пульте", а телефон выполняет.
  У нас два плагина: `Share` (поделиться) и `Filesystem` (файлы).

### Что делает команда `npm run sync`
Это **"ксерокс"**: копирует папку `www/` внутрь `android/` и `ios/`
и подключает плагины. Поэтому порядок работы всегда такой:

```
меняешь файлы в www/  →  npm run sync  →  запускаешь приложение заново
```

Если забыть `sync`, на телефоне будет старая версия.

### Паспорт приложения — `capacitor.config.json`
- `appName: "DroneLab"` — название под иконкой;
- `appId: "com.dronelab.app"` — уникальный "номер паспорта". Можно поменять,
  **пока приложение не опубликовано** в Google Play / App Store. После — нельзя;
- `webDir: "www"` — где лежит сайт;
- `SystemBars.style: "DARK"` — значит "фон тёмный", поэтому часы и батарейка сверху
  будут **светлыми**, чтобы их было видно.

## 5. Пошаговая инструкция: как запустить

### 5.1. Android-эмулятор (на твоём компьютере с Windows)

**Один раз — установить Android Studio:**
1. Скачай Android Studio с сайта developer.android.com/studio и установи
   (всё по умолчанию, "Next → Next → Finish"). Java ставится вместе с ней —
   отдельно ничего не нужно.
2. При первом запуске она сама докачает Android SDK. Подожди, это долго (10–30 минут).

**Каждый раз — запуск:**
1. Открой терминал в папке проекта (в VS Code: меню *Terminal → New Terminal*).
2. Выполни:
   ```
   npm run sync
   npm run android
   ```
   Вторая команда откроет проект в Android Studio.
3. **Первый раз** внизу Android Studio побежит полоска *"Gradle sync"* —
   она скачивает детали для сборки. Дождись, пока закончится (может быть 5–15 минут).
4. Создай виртуальный телефон: справа значок **Device Manager** (телефончик) →
   **"+" → Create Virtual Device** → выбери например **Pixel 8** → Next →
   выбери систему (самую верхнюю, со значком скачивания) → Next → Finish.
5. Наверху выбери этот телефон в списке и нажми зелёный треугольник **▶ Run**.
6. Через минуту эмулятор включится и откроется DroneLab. 🎉

**На настоящем Android-телефоне:** в телефоне включи *"Режим разработчика"*
(Настройки → О телефоне → 7 раз нажать на "Номер сборки"), потом в
*"Для разработчиков"* включи *"Отладка по USB"*. Подключи кабелем — телефон
появится в том же списке, где эмулятор.

### 5.2. iPhone

⚠️ **Важно:** приложения для iPhone собираются **только на Mac** с программой Xcode.
Это правило Apple, обойти на Windows нельзя. Варианты:
- одолжить Mac у друга / в школе / в компьютерном клубе;
- арендовать облачный Mac (MacinCloud и подобные);
- собирать в облаке через сервисы вроде Codemagic или Ionic Appflow (сложнее для новичка).

**На Mac — один раз:**
1. Установи **Xcode** из App Store (бесплатно, большой — около 10+ ГБ).
   Нужна свежая версия (Capacitor 8 требует Xcode 26 или новее).
2. Установи **Node.js** с сайта nodejs.org (версия 22 или новее).
3. Скопируй на Mac папку проекта **без** `node_modules` (она большая и
   всё равно скачается заново).

**На Mac — запуск:**
1. Открой Терминал в папке проекта и выполни:
   ```
   npm install
   npm run sync
   npm run ios
   ```
   Откроется Xcode.
2. Слева нажми на синюю иконку **App** → вкладка **Signing & Capabilities** →
   в поле **Team** выбери свой Apple ID (если пусто — *Add Account* и войди).
   Бесплатного Apple ID достаточно.
3. Подключи iPhone кабелем, на телефоне нажми **"Доверять этому компьютеру"**.
4. Наверху Xcode выбери свой iPhone в списке устройств и нажми **▶**.
5. На iPhone первый раз нужно:
   - включить **Режим разработчика**: Настройки → Конфиденциальность и безопасность →
     Режим разработчика → Вкл (телефон перезагрузится);
   - разрешить приложение: Настройки → Основные → VPN и управление устройством →
     твой Apple ID → **Доверять**.
6. Готово! 🎉

Можно и без iPhone: в том же списке устройств Xcode выбери симулятор, например
*iPhone 16*, и нажми ▶.

> С бесплатным Apple ID приложение на телефоне работает **7 дней**, потом его
> нужно снова установить из Xcode. С платным аккаунтом разработчика ($99/год) — год,
> и можно публиковать в App Store.

## 6. Частые ошибки и что делать

**"Я поменял файл, а в приложении ничего не изменилось"**
→ Забыл `npm run sync`. Выполни его и снова нажми ▶.
→ Ещё вариант: ты менял файл внутри `android/.../public` или `ios/App/App/public`.
  Эти папки перезаписываются при каждом `sync`! Меняй только в `www/`.

**Белый / пустой экран в приложении**
→ Скорее всего, ошибка в JavaScript или неправильный путь к файлу.
→ Как посмотреть ошибку на **Android**: открой в Chrome на компьютере адрес
  `chrome://inspect` — там появится твоё приложение, нажми *inspect* и открой вкладку *Console*.
→ На **iPhone**: в Safari на Mac включи меню *Разработка* (Настройки Safari →
  Дополнительно), затем *Разработка → твой iPhone → DroneLab*.

**`'cap' не является внутренней или внешней командой` / `cap: command not found`**
→ Не установлены инструменты. Выполни `npm install` в папке проекта.

**Android Studio: "SDK location not found" или ошибки Gradle**
→ Android Studio ещё не докачала SDK. Открой *Tools → SDK Manager*, поставь галочку
  на последнюю версию Android и нажми *Apply*. Потом *File → Sync Project with Gradle Files*.
→ Если пишет про Java / JDK — в *Settings → Build, Execution, Deployment → Build Tools → Gradle*
  выбери *Gradle JDK: jbr-21* (встроенная в Android Studio).

**Эмулятор очень медленный или не запускается**
→ В BIOS компьютера должна быть включена виртуализация (Intel VT-x / AMD-V).
→ Закрой лишние программы — эмулятору нужно много памяти.

**Xcode: "Signing for App requires a development team"**
→ Не выбран Team в *Signing & Capabilities* (шаг 2 в разделе про iPhone).

**iPhone: "Ненадёжный разработчик" / приложение не открывается**
→ Разреши его: Настройки → Основные → VPN и управление устройством → Доверять.
→ Прошло 7 дней (бесплатный Apple ID) — переустанови из Xcode.

**Кнопка "Поделиться" в браузере на компьютере просто скачивает файл**
→ Так и задумано. Окно "Поделиться" бывает только в приложении на телефоне.

**3D-дрон не появляется**
→ Телефон очень старый или в нём отключена 3D-графика (WebGL). Посмотри консоль (см. "белый экран").

**`npm install` пишет "3 moderate severity vulnerabilities"**
→ Это предупреждение про инструмент на компьютере (`@capacitor/cli`), в само приложение
  он не попадает. **Не запускай** `npm audit fix --force` — он может откатить версии и всё сломать.

**Хочу обновить three.js на новую версию**
→ Скачай новые `three.module.js` и `OrbitControls.js` в `www/libs/three/`.
  Внимание: в начале `OrbitControls.js` мы поменяли одну строчку —
  `from 'three'` на `from './three.module.js'`. В новом файле её надо поменять так же.
  (И в новых версиях three.js файл `three.module.js` может требовать соседний
  `three.core.js` — тогда скачай и его.)

## Шпаргалка команд

| Команда | Что делает |
|---|---|
| `npm install` | скачивает все инструменты (один раз или на новом компьютере) |
| `npm run sync` | копирует `www/` в Android и iOS ("ксерокс") |
| `npm run android` | открывает проект в Android Studio |
| `npm run ios` | открывает проект в Xcode (только на Mac) |
